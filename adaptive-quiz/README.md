# 과목 자유형 적응 학습 (Adaptive Quiz)

특정 과목에 종속되지 않는 진단평가 + 형성평가 기반 적응형 문제풀이 웹앱입니다.
교사가 문제를 등록하면 화학, 수학 등 어떤 과목이든 바로 사용할 수 있습니다.

- **학생**: 이름(학번)과 과목만 선택하면 진단평가 → 형성평가(단계별 적응형 4문제 라운드) → 성장 리포트까지 이어서 진행합니다.
- **교사**: 비밀번호로 보호된 교사 모드에서 과목/문제(진단평가·형성평가 별도) 등록·수정·삭제, 문제 엑셀(.xlsx) 업로드, 학생별 진단 결과·현재 단계·정답 이력·누적 점수 확인.
- 학생은 로그인 없이 이름만으로 구분되며, 교사 모드는 공유 비밀번호로 보호됩니다. 모든 진행 상황은 서버에 저장되어 새로고침하거나 다른 기기로 접속해도 유지됩니다(학생↔교사가 서로 다른 브라우저를 사용해도 동일한 데이터를 봅니다).
- 예시로 **화학**, **수학** 두 과목의 진단평가 10문항 + 형성평가(1~10단계 × 2문항 = 20문항)가 미리 채워져 있어 바로 체험할 수 있습니다.

## 아키텍처

```
adaptive-quiz/
  server/   Express API + JSON 파일 기반 저장소 (server/data.json, 배포 시 자동 생성)
  client/   Vite + React 프론트엔드
```

개발 중에는 두 프로세스를 따로 띄우고(Vite가 `/api`를 4000번 포트로 프록시),
운영 배포 시에는 `client`를 빌드한 뒤 `server`가 정적 파일과 API를 함께 서빙하는
**단일 Node 프로세스**로 동작합니다. 별도의 프런트/백엔드 서버를 분리 배포할 필요가 없습니다.

## 로컬 실행

```bash
npm run install:all   # server, client 의존성 설치
npm run seed           # 화학/수학 예시 과목·문제 데이터 생성 (server/data.json)

# 개발 모드 (터미널 2개)
npm run dev:server     # http://localhost:4000
npm run dev:client     # http://localhost:5173 (API는 자동 프록시)
```

`http://localhost:5173` 접속 후 우측 상단에서 학생 모드/교사 모드를 전환하세요.

## 배포

정적 파일 호스팅(Vercel 등)이 아니라 **Node 프로세스를 계속 띄워둘 수 있는 호스팅**(Render, Railway, Fly.io, 자체 VM/VPS 등)에 배포해야 합니다. 학생·교사 데이터를 `server/data.json` 파일에 저장하기 때문에, 배포 환경에 **영구 디스크(persistent disk)** 를 붙여야 재배포/재시작 후에도 데이터가 유지됩니다. (파일시스템이 매 요청마다 초기화되는 순수 서버리스 환경에는 적합하지 않습니다.)

배포 절차 예시:

```bash
npm run build   # client를 빌드해 server가 서빙할 수 있게 함
npm run seed    # 최초 1회: 예시 과목/문제 데이터 생성 (선택)
npm start       # server가 정적 파일 + API를 4000번 포트(PORT 환경변수로 변경 가능)에서 서빙
```

- `PORT`: 서버 포트 (기본 4000)
- `DB_PATH`: 데이터 파일 경로 (기본 `server/data.json`) — 영구 디스크 경로로 지정 권장
- `TEACHER_PASSWORD`: 교사 모드 접속 비밀번호 (기본값 `teacher1234`). **배포 환경에서는 반드시 직접 설정하세요** — Render 기준 대시보드 > 해당 서비스 > Environment 탭에서 `TEACHER_PASSWORD` 키를 추가하면 됩니다. 설정하지 않으면 서버 로그에 경고가 출력되고 기본값이 사용됩니다.

문제에 이미지를 많이 첨부할수록 `data.json` 파일 용량이 커집니다(이미지가 파일 안에 함께 저장되는 구조라서요). 학급 단위로 쓰는 정도면 문제되지 않지만, 이미지가 아주 많아지면 서버 응답이 느려질 수 있다는 점 참고하세요.

## 채점 / 적응형 규칙

### 진단평가 → 형성평가 시작 단계
`시작 단계 = round( (정답 수 / 전체 문항 수) × 10 )`, 1~10 범위로 고정합니다.
예: 10문항 중 7문항 정답 → 7단계에서 형성평가 시작. 진단평가 문항 수가 다르더라도 비율로 환산되므로 그대로 동작합니다.

### 형성평가 라운드 구성 (4문제)
- 2~9단계: 이전 단계(N-1) 문제 2개 + (N단계 또는 N+1단계) 문제 2개
- 1단계: 4문제 모두 1단계에서 출제
- 10단계: 4문제 모두 10단계에서 출제

### 라운드 종료 후 단계 조정
- 4문제 모두 정답 → 다음 단계로 상승
- 2문제 이하 정답 → 이전 단계로 하강
- 3문제 정답 → 현재 단계 유지
- 1단계에서 하강, 10단계에서 상승은 발생하지 않고 그대로 유지됩니다.

### 성장 점수
- 정답 1개당: **10점 + (문제 난이도 단계 × 2점)** — 어려운 단계일수록 더 높은 점수를 얻도록 설계
- 라운드 결과로 단계가 상승하면: **+30점 보너스**
- 오답/단계 하강에 따른 감점은 없습니다 (도전을 장려하기 위함)

세 규칙 모두 `server/scoring.js` 상수만 바꾸면 쉽게 조정할 수 있습니다.

## 교사 기능

- **로그인**: 교사 모드 진입 시 비밀번호(`TEACHER_PASSWORD`)를 입력해야 합니다. 한 번 입력하면 브라우저에 저장되어 새로고침해도 다시 로그인할 필요가 없고, 상단의 "로그아웃" 버튼으로 잠글 수 있습니다. 문제 정답이 포함된 조회 API·수정/삭제 API·학생 데이터 API는 모두 서버에서 이 비밀번호로 보호됩니다(학생이 API를 직접 호출해도 정답이나 다른 학생 기록을 볼 수 없습니다).
- **과목 관리**: 과목 추가/삭제(삭제 시 관련 문제·학생 기록도 함께 삭제됩니다)
- **문제 관리**: 과목 + 유형(진단평가/형성평가) + 단계(1~10)별로 문제를 조회·추가·수정·삭제
  - 문제 형식: 객관식 4~5지선다, 정답, 해설, 힌트(0~2개), 이미지(선택)
  - 화면에서 직접 추가하거나, **엑셀(.xlsx) 파일 업로드** 또는 JSON 붙여넣기로 여러 문제를 한 번에 등록할 수 있습니다.
  - **이미지 첨부**: 문제 추가/수정 화면에서 "이미지 선택"으로 사진이나 그림을 첨부할 수 있습니다. 업로드 시 자동으로 크기를 줄이고(긴 변 기준 최대 1000px) JPEG로 압축해서 저장하므로, 원본 파일이 커도 크게 신경 쓸 필요는 없습니다. 학생이 그 문제를 풀 때 문제 지문 아래에 이미지가 함께 표시됩니다. **엑셀 일괄 업로드에는 이미지를 넣을 수 없고, 이미지가 필요한 문제는 개별 추가/수정 화면에서 첨부해야 합니다** (엑셀로 다른 내용을 수정해도 기존에 붙여둔 이미지는 그대로 유지됩니다).
  - **단원**: 문제마다 단원(예: "1단원: 몰과 화학양론")을 선택적으로 붙일 수 있습니다. 문제 목록 위에 단원별 탭이 자동으로 생겨서, 한 과목 안에서도 단원별로 문제를 나눠 보고 관리할 수 있습니다. 단원은 교사가 문제를 정리하는 용도일 뿐이며, 학생의 진단평가·형성평가 흐름(과목당 진단평가 1개 + 1~10단계 형성평가)에는 영향을 주지 않습니다.
  - **엑셀로 기존 문제 수정**: "현재 문제 내보내기"로 받은 파일은 각 행에 문제 ID가 포함되어 있어, 내용을 고쳐서 그대로 다시 업로드하면 새 문제로 추가되지 않고 해당 문제가 수정됩니다(엑셀 안에서 여러 문제를 한 번에 고쳐서 반영할 때 유용합니다).
  - **전체 삭제**: 문제 목록의 "현재 목록 전체 삭제" 버튼으로, 지금 화면에 필터링된 문제(예: 특정 과목의 예시 문제 전체)를 한 번에 지울 수 있습니다. 기본 예시 문제를 지우고 새 세트로 완전히 교체하고 싶을 때 사용하세요.
- **학생 현황**: 과목별로 학생의 진단평가 결과, 현재 형성평가 단계, 누적 점수, 단계 상승/하강 이력, 최근 정답/오답 이력을 확인. 테스트용으로 학생별 진행 상황을 초기화할 수 있습니다.

## 학생 기능

1. 이름(또는 학번) + 과목 선택 후 시작
2. 진단평가(해당 과목의 진단평가 문제 전체)를 풀면 시작 단계가 자동 결정됨
3. 형성평가: 4문제 라운드를 반복하며 단계가 자동으로 오르내림
   - 문제마다 힌트 요청 가능(최대 2개), 제출 후 정답 여부와 해설을 확인
4. 성장 리포트: 진단평가 결과, 현재 단계(1~10 단계 시각화), 누적 점수, 정답률, 단계 변화 이력 확인

## 문제 일괄 업로드 형식

### 엑셀 업로드 (기본, 추천)

교사 모드 > 문제 관리 > "엑셀로 문제 업로드"에서 **양식 다운로드** 버튼을 누르면 아래 컬럼으로 구성된 `.xlsx` 파일이 받아집니다 ("설명" 시트에 작성 안내가 함께 들어있습니다).

| 유형 | 단계 | 단원 | 문제 | 보기1 | 보기2 | 보기3 | 보기4 | 보기5 | 정답 | 해설 | 힌트1 | 힌트2 | ID |
|---|---|---|---|---|---|---|---|---|---|---|---|---|---|
| 진단평가 또는 형성평가 | 1~10 | 선택(자유 텍스트) | 문제 지문 | 필수 | 필수 | 필수 | 필수 | 선택(5지선다일 때만) | A~E 또는 보기 번호(1~5) | 해설 | 선택 | 선택 | 새 문제는 비워둠 |

`2행`부터 실제 문제를 채운 뒤 "엑셀 파일 선택"으로 그 파일을 업로드하면, 현재 화면에서 선택된 과목에 한 번에 등록됩니다. 행 단위로 오류가 있으면 몇 번째 행에 어떤 문제가 있는지 표시됩니다.

**기존 문제를 수정하려면** "새 문제로 추가"가 아니라 **"현재 문제 내보내기"** 버튼을 눌러 지금 등록된 문제를 엑셀로 받으세요. 이 파일은 각 행 맨 끝에 `ID` 값이 채워져 있는데, 이 값을 그대로 둔 채 다른 칸(문제/보기/정답/해설/힌트 등)만 고쳐서 업로드하면 **새로 추가되지 않고 해당 ID의 기존 문제가 수정**됩니다. `ID`가 비어 있는 행은 새 문제로 추가됩니다. 행을 지운다고 해서 그 문제가 자동 삭제되지는 않으며, 삭제는 화면의 "삭제"(개별) 또는 "현재 목록 전체 삭제"(일괄) 버튼으로 합니다.

### JSON 업로드 (고급)

같은 화면의 "일괄 업로드 (JSON, 고급)"에서 아래와 같은 JSON 배열을 붙여넣을 수도 있습니다 (`subjectId`는 화면에서 선택한 과목으로 자동 채워집니다):

```json
[
  {
    "type": "formative",
    "level": 3,
    "stem": "문제 내용을 입력하세요",
    "choices": ["보기1", "보기2", "보기3", "보기4"],
    "answerIndex": 0,
    "explanation": "해설 내용",
    "hints": ["힌트1", "힌트2"]
  }
]
```
