# 카테고리 솔리테어

단어 카드를 알맞은 카테고리 칸으로 분류하는 솔리테어형 형성평가 게임입니다.

> **진행 상황:** ① 게임 화면과 규칙 완료 → ② 엑셀 업로드 → ③ 저장과 결과 대시보드 → ④ 교사 계정과 수업 코드
> 운영자용·교사용 전체 안내는 ④단계를 마칠 때 이 문서에 채웁니다.

## 지금 바로 해 보기 (①단계)

```bash
cd category-solitaire
npm install
npm run dev      # 화면에 나오는 주소(예: http://localhost:5173)를 브라우저로 열기
```

같은 와이파이의 휴대폰에서 보려면 `npm run dev -- --host`로 실행한 뒤 화면에 나오는 `Network` 주소로 접속하세요.

## 게임 규칙

- 카테고리 카드(금색, ★)를 위쪽 빈 칸에 놓으면 그 칸이 열립니다.
- 단어 카드를 알맞은 칸에 놓으면 쌓이고, 틀리면 흔들리며 제자리로 돌아옵니다.
- 끌어다 놓기 또는 "카드 탭 → 칸 탭" 둘 다 됩니다.
- 맨 위 카드는 다른 열로 옮길 수 있고, 왼쪽 더미를 탭하면 한 장씩 넘어갑니다.
- 화면이 좁으면 카드가 너무 작아지지 않게 열 수가 자동으로 줄어듭니다.

## 점수 공식 (기본값)

| 항목 | 점수 |
|---|---|
| 단어 카드 정답 | +10 |
| 카테고리 카드로 칸 열기 | +2 |
| 단어 카드 오답 | −5 |
| 시간 보너스 | (카드 수 × 6초 − 걸린 시간) × 0.2, 0 미만이면 0. 모두 분류했을 때만 |
| 추가 이동 감점 | (전체 이동 − 카드 수) × 1, 최대 20 |

최종 점수는 0점 아래로 내려가지 않습니다. 값은 `src/settings.js`의 `DEFAULT_SETTINGS`에 있고, ④단계에서 교사 설정 화면으로 옮겨집니다.

## 파일 구조

```
category-solitaire/
├─ index.html          첫 화면 틀
└─ src/
   ├─ main.js          화면 전환 (시작 → 게임 → 결과)
   ├─ board.js         게임 화면 그리기, 드래그·탭 조작, 타이머
   ├─ game.js          게임 규칙 (카드 섞기·배치·정답 판정)
   ├─ settings.js      설정 기본값과 점수 계산
   ├─ sample-set.js    샘플 세트 (고등 화학)
   └─ style.css        디자인 (색상 테마 포함)
```
