# 카테고리 솔리테어

단어 카드를 알맞은 카테고리 칸으로 분류하는 솔리테어형 **형성평가 게임**입니다.
교과에 상관없이 엑셀로 내용만 바꿔 쓸 수 있고, 여러 학교·교과의 교사가 한 주소를 함께 쓰면서도 교사별로 데이터가 분리됩니다.

- **학생**: 로그인 없이 `수업 코드 + 학번`으로 입장 → 게임 → 점수·틀린 단어·해설·내 점수 변화 그래프
- **교사**: 가입 → 엑셀로 게임 세트 만들기 → 수업(반)마다 수업 코드 만들기 → 공개할 세트·점수 규칙 설정 → 결과 대시보드

## 운영자용 (처음 한 번만)

학교나 교과 모임에서 한 명이 아래를 한 번 해 두면, 다른 교사들은 주소만 받아 가입해서 씁니다.
필요한 것: GitHub 계정(이 저장소), [Supabase](https://supabase.com) 계정(데이터 저장소, 무료), [Vercel](https://vercel.com) 계정(웹 배포, 무료).

> 서비스 화면의 메뉴 이름은 조금씩 바뀔 수 있어요. 이름이 다르면 비슷한 메뉴를 찾아 주세요.

### 1. 데이터 저장소 만들기 (Supabase)

1. supabase.com 에 가입하고 **New project** 를 누릅니다.
2. 프로젝트 이름(예: `category-solitaire`)과 데이터베이스 비밀번호를 정하고, Region 은 **Northeast Asia (Seoul)** 을 고른 뒤 **Create new project**.
   - 데이터베이스 비밀번호는 앱에서 쓰지 않아요. 따로 안전하게 보관만 하세요.
3. 왼쪽 메뉴 **SQL Editor** → **New query** 를 엽니다.
4. 이 저장소의 [`supabase/schema.sql`](supabase/schema.sql) 내용을 **전부 복사해 붙여 넣고 Run** 을 누릅니다. `Success` 가 나오면 끝이에요.
   - 표(세트·수업·공개 세트·학생 기록), 교사별 데이터 분리 규칙, 학생용 함수가 한 번에 만들어져요.
   - 나중에 이 파일이 바뀌면 같은 방법으로 다시 Run 하면 됩니다(기존 데이터는 지워지지 않아요).
   - ⚠️ **상점 기능을 추가한 버전으로 업데이트할 때도 꼭 다시 Run 하세요.** 안 하면 게임 기록은 저장되지만 코인이 쌓이지 않고 상점을 쓸 수 없어요.

### 2. 연결 정보 확인

**Project Settings → API**(또는 **API Keys / Data API**) 화면에서 두 값을 복사해 둡니다.

| 이름 | 어디에 있나 | 예 |
|---|---|---|
| Project URL | Project URL | `https://abcd1234.supabase.co` |
| anon public 키 | Project API keys 의 `anon` `public` | `eyJhbGciOi...` |

> ⚠️ `service_role` 키(또는 secret 키)는 **절대** 쓰지 마세요. 모든 보안 규칙을 무시하는 관리자 키입니다.
> `anon` 키는 원래 브라우저에 공개되는 키이고, 실제 보호는 1-4에서 만든 규칙이 맡습니다.

### 3. 무료 배포 (Vercel)

1. vercel.com 에 **GitHub 계정으로 로그인**합니다.
2. **Add New… → Project** → 이 저장소를 **Import** 합니다.
3. 설정 화면에서
   - **Root Directory**: `category-solitaire` 를 고릅니다. (중요)
   - **Framework Preset**: `Vite` (자동으로 잡혀요)
   - **Environment Variables** 에 두 줄을 추가합니다.
     - `VITE_SUPABASE_URL` = 2번의 Project URL
     - `VITE_SUPABASE_ANON_KEY` = 2번의 anon public 키
4. **Deploy** → 몇 분 뒤 `https://프로젝트이름.vercel.app` 주소가 생겨요. 이 주소를 교사들에게 알려 주면 됩니다.
   - 환경 변수를 나중에 바꿨다면 Vercel 의 **Deployments → … → Redeploy** 를 해야 적용돼요.

### 4. 교사 가입 메일 설정 (Supabase)

1. **Authentication → URL Configuration**
   - **Site URL** 에 3번의 배포 주소(예: `https://category-solitaire.vercel.app`)를 넣습니다.
   - **Redirect URLs** 에도 같은 주소를 추가합니다.
   - 이걸 안 하면 가입 인증 메일·비밀번호 재설정 메일의 링크가 엉뚱한 곳으로 가요.
2. (권장) Supabase 기본 메일 서버는 **시간당 보낼 수 있는 메일 수가 아주 적어요.** 여러 교사가 한꺼번에 가입한다면
   **Authentication → Emails → SMTP Settings** 에서 학교·기관 메일 서버를 연결하세요.
3. (선택) 아무나 가입하지 못하게 하려면 **Authentication → Sign In / Providers** 에서 새 사용자 가입(Allow new users to sign up)을 끄고,
   **Authentication → Users → Invite user** 로 교사를 초대하세요.

### 5. 알아 둘 점

- **무료 요금제 일시 정지**: Supabase 무료 프로젝트는 **7일 동안 아무도 쓰지 않으면 일시 정지**돼요. 방학 뒤 접속이 안 되면
  Supabase 대시보드에서 프로젝트를 열고 **Restore(복원)** 를 누르세요. 데이터는 남아 있어요.
- **백업**: 교사는 수업별 결과를 CSV로 받을 수 있어요. 학기 말에 CSV로 받아 두고 기록을 지우는 것을 권장합니다.
- **개인정보**: 학생은 학번(필수)과 이름(선택)만 입력해요. 교사는 자기 수업 기록만 보고 지울 수 있고, 다른 교사의 데이터에는 접근할 수 없어요.
  수업 코드와 학번을 모두 아는 사람은 그 학생의 해당 세트 점수 변화만 볼 수 있어요(게임을 한 번 끝내야 보임).
- **점수 조작 방지**: 서버가 세트 크기와 수업 설정으로 가능한 최고 점수를 계산해 그보다 높은 점수는 받지 않아요.
  다만 형성평가용이라 브라우저에서 계산한 결과를 믿는 구조예요. 성적 반영용 시험에는 쓰지 마세요.

### 6. (선택) 생기부 문장 초안 AI 켜기

교사 결과 화면의 **📝 생기부** 버튼은 Claude(AI)로 세특 문장 초안을 만들어요. 쓰려면 운영자가 API 키를 한 번 넣어야 해요.

1. [console.anthropic.com](https://console.anthropic.com) 에 가입 → **Billing** 에서 결제 수단 등록(선불 충전) → **API Keys → Create Key** 로 키(`sk-ant-...`)를 만들어 복사해요.
2. Vercel 프로젝트 → **Settings → Environment Variables → Add** 에서
   - Key: `ANTHROPIC_API_KEY` (⚠️ 앞에 `VITE_` 를 **붙이지 마세요**. 붙이면 키가 화면 코드에 드러나요)
   - Value: 복사한 키, Type: **Secret**, Environments: Production → **Save**
3. **Deployments → 맨 위 ⋯ → Redeploy** 로 다시 배포해요.
4. (선택) 특정 학교·교육청 메일로 가입한 교사만 AI를 쓰게 하려면 `AI_ALLOWED_EMAIL_DOMAINS` 변수를 `sen.go.kr,korea.kr` 처럼 추가하세요.

- 비용: 학생 1명당 대략 10~30원(Claude Opus 5.5 기준, 분량에 따라 다름). Anthropic 콘솔 **Usage** 에서 사용량을 볼 수 있고, **Limits** 에서 월 한도를 정해 두면 안전해요.
- 개인정보: 학생 **이름·학번은 AI로 보내지 않아요.** 게임 기록 요약(참여 횟수, 정확도 변화, 헷갈린 개념)과 교사가 쓴 메모만 보내요. 학교 방침에 맞는지 확인하고 쓰세요.
- 키를 넣지 않으면 버튼을 눌렀을 때 "AI 기능이 아직 설정되지 않았어요"라고 나오고, 나머지 기능은 그대로 쓸 수 있어요.

### 내 컴퓨터에서 실행하기 (선택)

```bash
cd category-solitaire
npm install
cp .env.example .env     # .env 파일을 열어 2번의 두 값을 채우기
npm run dev              # 화면에 나오는 주소(예: http://localhost:5173)를 브라우저로 열기
```

- `.env` 없이 실행하면 **체험 모드**예요. 로그인 없이 교사 화면을 쓸 수 있고, 모든 데이터는 그 브라우저에만 저장돼요.
  체험 수업 코드는 `DEMO23` 입니다.
- 같은 와이파이의 휴대폰으로 보려면 `npm run dev -- --host` 로 실행한 뒤 `Network` 주소로 접속하세요.

## 교사용

### 1. 가입과 로그인

1. 운영자에게 받은 주소로 들어가 아래의 **교사이신가요? 교사 화면으로** 를 누릅니다.
2. **처음이신가요? 가입하기** → 이메일과 비밀번호(6자 이상) 입력.
3. 메일함의 **인증 링크**를 누르면 가입이 끝나요. 그다음부터는 이메일·비밀번호로 로그인합니다.
   - 비밀번호를 잊었다면 **비밀번호를 잊으셨나요?** → 메일의 링크 → 새 비밀번호.

### 2. 엑셀로 게임 세트 만들기 — [게임 세트] 탭

1. **빈 양식 받기**를 눌러 양식을 받아요. 예시가 필요하면 **샘플 세트 엑셀 받기**나 **샘플 세트(고등 화학) 추가**를 누르세요.
2. 양식을 채웁니다.

   | A열 | B열 | C열 |
   |---|---|---|
   | 카테고리 | 단어 | 해설(선택) |
   | 산·염기 | pH | 수용액의 산성도를 나타내는 척도 |

   - **시트 이름 = 세트 이름**이에요. 시트를 여러 개 만들면 한 번에 여러 세트가 올라가요.
   - 한 단어는 한 카테고리에만 넣어 주세요. 카테고리는 2개 이상 필요해요.
   - 과학(단원·개념), 영어·독일어(품사·주제) 등 어떤 교과든 됩니다. ä, ö, ü, ß 도 그대로 써요.
3. 파일을 올리면 시트마다 검사 결과가 나와요.
   - **오류**(빨강, 저장 불가): 빈칸, 중복 단어, 한 단어가 두 카테고리에, 카테고리 1개뿐, 글자 수 초과 — 엑셀 **행 번호**가 함께 나와요.
   - **주의**(노랑, 저장 가능): 단어가 1개뿐인 카테고리, 긴 단어, 카테고리가 너무 많음 등
4. **저장 전에 해 보기**로 미리 플레이한 뒤 **선택한 세트 저장**. 같은 이름으로 다시 올리면 덮어써요.

### 3. 수업 코드 만들기 — [수업] 탭

1. **새 수업 이름**(예: `2학년 3반 화학`) → **수업 만들기**. 6자리 **수업 코드**가 생겨요.
2. **공개 세트**: 이 반 학생에게 보여 줄 세트를 체크하고 **저장**.
3. **설정**(반마다 다르게 할 수 있어요)
   - 카드 열 개수, 색상 테마, 카테고리 카드 섞기(끄면 쉬움), 시간 제한
   - 점수 공식의 각 값 — 화면에 공식이 바로 보여요. **이 설정으로 해 보기**로 확인 후 **설정 저장**.
4. 학생에게 알려 주기: 수업 화면의 **QR 코드**를 누르거나 **QR 크게 보기**로 교실 화면에 띄우세요.
   학생이 휴대폰 카메라로 찍으면 수업 코드가 채워진 채로 열려서 **학번만** 입력하면 돼요.
   **그림으로 저장**으로 QR을 이미지로 받아 학습지에 넣을 수도 있고, 수업 코드를 칠판에 쓰거나 **입장 주소 복사**로 공유해도 돼요.

### 4. 학생 상점 (코인으로 카드 뒷면 사기)

- 학생이 게임을 끝낼 때마다 **점수의 1/10이 코인**으로 쌓여요(수업마다 따로).
- 세트 고르는 화면의 **🛒 카드 뒷면 상점**에서 코인으로 카드 뒷면 디자인 10가지(무료~500코인)를 사고 골라 쓸 수 있어요.
- 처음 살 때 학생이 **상점 비밀번호(숫자 4자리)** 를 정해요. 친구가 학번만 알고 대신 코인을 쓰는 걸 막아 줘요.
  5번 틀리면 10분 동안 잠겨요. 학생이 비밀번호를 잊으면 [결과] 탭 학생별 기록의 **상점 비밀번호 초기화**를 누르세요(코인은 그대로).
- 상점을 쓰지 않으려면 수업 [설정]에서 **학생 상점 사용**을 끄세요. 코인은 계속 쌓이고, 다시 켜면 그대로 쓸 수 있어요.
- 가격·디자인은 `src/card-backs.js`, `src/style.css`, `supabase/schema.sql`(shop_price) 세 곳에 있어요.

### 5. 결과 보기 — 수업의 [결과] 탭

- **요약**: 참여 학생 수, 전체 시도, 평균 점수, 배치 정확도
- **문항(단어)별 오답률 순위**: 그 단어를 한 번 이상 틀린 시도의 비율 — 다시 설명할 개념을 찾을 때
- **혼동 쌍**: 어떤 단어를 어느 칸에 잘못 넣었는지, 몇 번·몇 명 — 헷갈리는 개념 쌍을 찾을 때
- **학생별 기록**: 학번, 이름, 시도 횟수, 최고 점수, 최근 점수, 코인
- 위쪽 **세트** 목록으로 세트별로 나눠 볼 수 있어요.
- **CSV 다운로드**: 엑셀에서 바로 열려요(한글 깨짐 없음).
- **삭제**: 학생별 [삭제] 또는 **이 수업 기록 모두 삭제**(수업 코드를 입력해야 지워져요).
  수업 자체를 지우려면 [설정] 맨 아래 **수업 삭제**.

### 6. 생기부(세특) 문장 초안 — 수업의 [결과] 탭

- 학생별 기록의 **📝 생기부** → 근거 요약(참여 횟수, 정확도 변화, 처음엔 틀렸다가 바르게 분류한 개념, 아직 헷갈리는 개념)을 확인하고 **AI로 초안 만들기**.
  과목, 분량, **교사 관찰 메모**(선택)를 넣으면 반영돼요. 나온 문장은 바로 고치고 **복사**할 수 있어요.
- 분량은 기본이 **자동**이에요. 참여 1회 1문장, 2~3회 2문장, 4~5회 3문장, 6회 이상 4문장(교사 메모가 있으면 1문장 더, 최대 4문장). 짧게(1~2문장)·길게(3~4문장)로 바꿀 수도 있어요.
- 위쪽 **📝 반 전체 생기부 초안** → 반 학생 모두의 초안을 만들어 **CSV(엑셀)** 로 받아요. 실패한 학생만 다시 만들 수 있어요.
- 위쪽 **세트** 목록으로 고른 세트의 기록만 근거로 쓸 수도 있어요.
- 문장은 **성장 관점**(처음 헷갈린 점 → 반복하며 노력한 과정 → 달라진 점 → 앞으로의 기대)으로, 명사형(~함, ~됨)과 숫자 없는 표현으로 써요. 범주 이름을 모두 나열하지 않고 활동 주제로 묶어요. 참여가 1회뿐이면 "근거 부족"을 알려 줘요.
- ‘흥미, 열정, 적극성’ 같은 감정·태도 표현은 **교사 관찰 메모에 쓴 경우에만** 들어가요. 한 문장은 90자 이내로 나눠 써요.
- ⚠️ AI가 게임 기록만 보고 쓴 **초안**이에요. 세특은 교사의 관찰을 바탕으로 써야 하니 꼭 확인하고 고쳐 쓰세요. 메모에는 학생 이름 등 개인정보를 쓰지 마세요.

## 학생 안내

1. 선생님이 알려 준 주소로 들어가요.
2. **수업 코드**(6자리)와 **학번**을 입력해요. 이름은 쓰지 않아도 돼요.
3. 세트를 골라 게임을 하고, 끝나면 점수·틀린 단어와 해설·내 점수 변화 그래프를 확인해요.
4. 모은 코인으로 **🛒 카드 뒷면 상점**에서 좋아하는 카드 뒷면을 사요. 처음 살 때 정한 비밀번호 4자리를 꼭 기억하세요.

## 게임 규칙과 점수

- 카테고리 카드(금색 ★)를 빈 칸에 놓으면 칸이 열리고, 단어 카드를 알맞은 칸에 놓으면 겹쳐 쌓여요. 틀리면 흔들리며 제자리로 돌아와요.
- 카드 열에서 한 번 앞면이 된 카드는 다른 카드에 덮여도 윗부분(단어)이 보여요.
- 그 윗부분을 끌거나 탭하면 **그 카드부터 맨 위 카드까지 한 묶음**으로 움직여요.
  - 카테고리 칸에 놓을 때 모두 맞으면 한 번에 쌓이고, 하나라도 틀리면 모두 제자리로 돌아가요(틀린 카드마다 오답 1번).
  - 묶음 이동은 1번으로 세요. 카테고리 카드(★)는 한 장씩 옮겨요.
- 끌어다 놓기와 "카드 탭 → 칸 탭" 둘 다 됩니다. 맨 위 카드는 같은 카테고리 카드 위나 빈 열로 옮길 수 있고, 더미를 탭하면 한 장씩 넘어가요.
- 카드 순서는 매번 무작위이고, 모든 단어를 분류하면 끝나요(시간 제한을 켜면 시간이 다 돼도 끝).

**점수 공식 (기본값, 교사가 수업별로 바꿀 수 있음)**

```
점수 = 단어 정답 × 10 + 카테고리 칸 열기 × 2 − 오답 × 5
     + 시간 보너스  (카드 수 × 6초 − 걸린 시간) × 0.2   ← 모두 분류했을 때만, 0 미만은 0
     − 추가 이동    (전체 이동 − 카드 수) × 1           ← 최대 20점
0점 미만은 0점
```

## Claude Code에 수정 요청하기

Claude Code에 아래처럼 **무엇을·어디서·어떻게** 바꾸고 싶은지 구체적으로 말하면 좋아요.

- "카테고리 솔리테어에서 정답 가점 기본값을 10점에서 5점으로 바꿔 줘."
- "학생 결과 화면에 반 평균 점수도 같이 보여 줘."
- "엑셀 업로드에서 단어 최대 글자 수를 40자에서 60자로 늘려 줘."
- "게임 중 틀리면 나는 진동을 없애 줘."
- "색상 테마에 ‘분홍’을 추가해 줘."
- "상점에 ‘벚꽃’ 카드 뒷면을 150코인으로 추가해 줘."
- "생기부 초안 문장을 조금 더 짧게, ‘~함’ 대신 ‘~하는 모습을 보임’ 표현을 쓰게 바꿔 줘."
- "결과 대시보드에 날짜 범위로 거르는 기능을 추가해 줘."
- "학생 입장 주소를 QR 코드로도 보여 줘."
- "supabase/schema.sql 을 바꿨는데 운영 중인 데이터베이스에 어떻게 적용하면 돼?"
- "카드 뒷면 무늬를 줄무늬 대신 학교 로고 색으로 바꿔 줘."

수정 뒤에는 "휴대폰 화면 크기로 한 판 끝까지 해 보고 확인해 줘"라고 덧붙이면 동작까지 확인해 줘요.
